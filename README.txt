POKEMON GO FRIEND TRACKER — BETA

Each tester's data is private and stored only in that person's browser on that device.
There is no shared database, account or cloud sync, so testers cannot see one another's information.

HOW TO TRY IT
1. Extract the ZIP fully.
2. Open index.html in a modern browser.
3. Do not open index.html from inside the ZIP preview; extract it first.

DATA NOTES
- Clearing browser/site data deletes that tester's tracker data.
- Moving to another device does not automatically move the data.
- Use Export backup before changing device or clearing browser data.
- Use Import backup to restore a previously exported JSON backup.

For the most reliable phone testing, testers can use any simple local-file web app viewer or open the extracted index.html in a browser that supports local HTML files. No Netlify or shared hosting is required.
